# 데이터 안내

대학 입학성과 분석에 사용한 원자료와 가공 데이터의 구성 및 해석 기준을 정리한다.

## 출처와 기간

| 출처 | 사용 자료 | 기간 및 저장 위치 |
| --- | --- | --- |
| [대학알리미](https://www.academyinfo.go.kr/) | 신입생 충원현황, 졸업생 취업현황 | 공시연도 2023~2025, `raw/academyinfo/` |
| [KOSIS 국가통계포털](https://kosis.kr/) | 시도별 18세 인구 | 2023~2025, `raw/kosis/` |
| [교육통계서비스](https://kess.kedi.re.kr/) | 고등학교 졸업 후 상황: 졸업자수·진학자수 | 1999~2025 원파일에서 2023~2025 사용, `raw/kess/` |

위 기간은 데이터의 기준·공시연도이며 다운로드 날짜가 아니다. 정확한 수집일과 개별 통계표 URL은 현재 저장소에 별도 기록되어 있지 않다. 재수집 시 통계표명·조회 조건·다운로드 날짜·이용조건을 함께 기록한다.

## 분석 단위와 결합 기준

- 대상: [선정 대학 목록](interim/target_universities.csv)의 **22개 대학 × 2023~2025년 = 66개 대학-연도**. 전체 대학을 대표하는 표본으로 해석하지 않는다.
- 대학별 데이터는 대학명과 연도로 결합하며, 지역 인구·고교 지표는 지역과 기준연도로 연결한다. 같은 지역·연도의 대학에는 동일한 지역 지표가 반복된다.
- 취업성과는 **공시연도 2023/2024/2025 → 자료연도 2022/2023/2024**이다. 입학성과 기준연도에 공시연도를 맞추고 `자료연도`, `취업성과_자료시차`로 1년 시차를 보존한다.
- 복수 캠퍼스 등 대학별 원자료가 여러 행이면 인원을 합산한 뒤 비율을 재계산한다.

## 폴더와 주요 파일

| 경로 | 역할 |
| --- | --- |
| `raw/` | 제공처별 원본 Excel. 전처리 입력 자료 |
| `interim/` | 대상 대학 목록 및 지역·설립구분·분석그룹 등 결합 기준 정보 |
| `processed/` | 정제·통합한 CSV와 집계·상관분석 결과. 모든 파일이 66행인 것은 아님 |
| [검증 결과](../reports/data_validation/) | 충원율·경쟁률 및 취업성과 검증 결과 |

주요 분석 입력은 다음과 같다.

- [입학성과 기본 자료](processed/freshman_fill_rate_target_universities.csv)
- [인구·고교 지표 결합 자료](processed/freshman_fill_rate_with_population_graduation.csv)
- [취업성과 결합 자료](processed/freshman_fill_rate_with_employment.csv)
- [Power BI용 자료](../reports/powerbi_dashboard_dataset/)는 별도 산출물 폴더에서 관리한다.

## 주요 변수

인원 단위는 명, 비율 단위는 %이며 경쟁률은 배수이다.

| 변수 | 정의 |
| --- | --- |
| `기준연도`, `대학명` | 대학-연도 식별 기준 |
| `지역`, `설립구분`, `수도권/지방`, `분석그룹` | 대학 특성 및 비교 그룹 |
| `입학정원` | 원자료의 입학정원. 충원율 계산 분모인 모집인원과 구분 |
| `모집인원`, `지원자`, `입학자` | 정원내 인원. `_전체` 접미사 변수는 원자료 전체 인원 |
| `정원내 신입생 충원율(%)` | 정원내 입학자 ÷ 정원내 모집인원 × 100, 소수 첫째 자리 |
| `경쟁률` | 정원내 지원자 ÷ 정원내 모집인원, 소수 첫째 자리 |
| `18세_인구` | 해당 지역·연도의 18세 인구 |
| `고등학교_졸업자수`, `고등학교_진학자수`, `고등학교_진학률` | 지역별 고교 지표. 고교 진학률 = 진학자수 ÷ 졸업자수 × 100 |
| `취업률_계산분모` | 졸업자 − 진학자 − 입대자 − 취업불가능자 − 외국인유학생 − 제외인정자 |
| `취업률(%)` | 취업자 ÷ 취업률 계산분모 × 100, 소수 둘째 자리 |
| `진학률(%)` | **대학 졸업자** 중 진학자 ÷ 졸업자 × 100, 소수 둘째 자리. 고교 진학률과 구분 |

## 검증 및 재현

기존 저장 결과에서 충원현황 원자료 69행과 최종 대학-연도 66행이 모두 PASS이며, 취업성과 검증도 66행 모두 PASS이다. 이는 저장된 검증 결과이며, 데이터를 갱신하면 다시 실행해야 한다.

- [충원율 검증](../scripts/validate_freshman_fill_rate.py): 원자료와 가공자료의 인원·충원율·경쟁률 대조.
- [취업성과 검증](../scripts/validate_employment_processed.py): 행 수·중복·대학/연도 구성, 분모 및 비율 재계산, 저장된 공시율 대조. 재계산 허용오차는 0.01, 공시 취업률은 0.11%p이며 복수 원자료 행의 공시율 단순평균 비교는 제외한다. 이 검증 스크립트는 가공 CSV를 읽으므로 원본 Excel의 독립 재추출 검증과 구분한다.
- 지역 지표를 갱신할 때는 결합 전 지역-연도 중복과 결합 후 결측·행 수 증가를 확인한다.

저장소 루트에서 의존성을 설치한 후 실행한다. 검증 명령은 `reports/data_validation/`의 결과를 갱신한다.

```sh
python -m pip install -r requirements.txt
python scripts/validate_freshman_fill_rate.py
python scripts/validate_employment_processed.py
```

## 원자료 재배포

원자료의 권리와 이용조건은 각 제공처 및 개별 자료의 조건을 따른다.

본 저장소의 공개 버전에는 대학알리미, KOSIS 국가통계포털, 교육통계서비스에서 내려받은 원본 Excel 파일을 포함하지 않는다. 원자료는 각 공식 제공처에서 직접 획득해야 하며, 필요한 자료명과 기간 및 저장 위치는 위의 「출처와 기간」을 참고한다.

`raw/` 디렉터리는 전처리 코드에서 기대하는 폴더 구조를 보여주기 위해 유지한다. 분석에 사용한 정제·가공 데이터와 분석 코드는 저장소에서 확인할 수 있다.

원자료 및 가공자료를 재사용할 때에는 각 제공처의 이용조건과 출처표시 기준을 확인한다.
