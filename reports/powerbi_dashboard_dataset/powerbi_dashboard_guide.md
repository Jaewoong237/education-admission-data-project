# Power BI 대시보드 구성 가이드

## 1. 사용 데이터

- `powerbi_university_year_panel.csv`: 대학-연도 단위 패널 데이터
- `powerbi_university_summary.csv`: 대학별 3개년 평균 및 전략 유형 요약 데이터
- `powerbi_strategy_type_counts.csv`: 전략 유형별 대학 수
- `powerbi_model_performance.csv`: 예측모형 성능 비교
- `powerbi_cv_model_performance.csv`: 교차검증 성능 비교
- `powerbi_feature_importance.csv`: 랜덤포레스트 변수 중요도
- `powerbi_research_question_summary.csv`: 연구문제별 분석 요약
- `powerbi_kpi_summary.csv`: 대시보드 핵심 KPI 요약

## 2. 권장 대시보드 페이지

### Page 1. 프로젝트 개요
- 카드: 분석 대학 수, 분석 연도 수, 평균 충원율, 평균 경쟁률, 평균 취업률
- 표: 연구문제별 분석 방법 및 주요 결과

### Page 2. 입학성과 현황
- 막대그래프: 대학별 평균 신입생 충원율
- 꺾은선그래프: 연도별 평균 신입생 충원율
- 슬라이서: 연도, 지역, 수도권/지방, 분석그룹

### Page 3. 취업성과 및 입시지표 관계
- 산점도: 취업률 vs 신입생 충원율
- 산점도: 경쟁률 vs 신입생 충원율
- 산점도: 진학률 vs 신입생 충원율

### Page 4. 대학별 전략 유형
- 막대그래프: 전략 유형별 대학 수
- 표: 대학별 전략 유형, 전략 점수, 전략 인사이트
- 슬라이서: 전략 유형, 지역, 수도권/지방

### Page 5. 예측모형 결과
- 막대그래프: 모형별 RMSE 비교
- 막대그래프: 랜덤포레스트 변수 중요도
- 산점도: 실제 충원율 vs 예측 충원율

## 3. 대시보드 핵심 메시지

본 대시보드는 신입생 충원율을 중심으로 학령인구 흐름, 취업성과, 경쟁률, 진학률, 대학별 전략 유형, 예측모형 결과를 통합적으로 확인할 수 있도록 구성한다.
이를 통해 대학별 입학성과를 단일 지표가 아니라 외부 환경, 입시 수요, 취업성과, 안정성, 예측 가능성을 종합하여 진단할 수 있다.
