# 대학 입학성과 프로젝트 발표 방어 가이드

이 문서는 최종 발표 슬라이드의 흐름과 주요 질의응답 포인트를 정리한 발표용 참고자료이다. 최종 보고서·PPT·분석결과 자체는 수정하지 않고, 발표 시 설명 논리를 보완하기 위한 용도로 사용한다.

## 1. 전체 발표 스토리

문제 제기 → 데이터 구축·검증 → 외부환경 탐색 → 주요 지표 관계 분석 → 대학 유형화 → 예측 가능성 탐색 → Power BI 통합 → 결론

핵심 메시지는 다음과 같다.

> 대학 입학성과를 단일 지표로 설명하지 않고, 신뢰할 수 있는 공공데이터를 구축한 뒤 외부환경과 주요 성과지표의 관계를 분석하고, 이를 대학별 전략 진단과 예측으로 확장하여 최종적으로 대시보드까지 구현하였다.

## 2. 슬라이드 연결 멘트

### 슬라이드 7 → 8

> 특정 하나의 변수만으로 신입생 충원율을 충분히 설명하기 어렵다는 결과가 나타났습니다. 따라서 다음 단계에서는 각 지표를 개별적으로 보기보다 충원율·경쟁률·취업률·충원 안정성을 함께 고려하여 대학별 입학성과 구조를 종합적으로 진단했습니다.

### 슬라이드 8 → 9

> 앞에서는 여러 지표를 조합하여 대학의 현재 상태를 진단했습니다. 그렇다면 같은 정보들을 동시에 활용했을 때 충원율이라는 결과값 자체를 어느 정도 예측할 수 있는지도 확인해보고자 했습니다.

### 슬라이드 9 → 10

> 단일 평가분할에서는 Random Forest가 상대적으로 양호했지만 교차검증에서는 일반화 성능의 한계가 확인되었습니다. 따라서 예측값 하나를 의사결정 결과로 제시하기보다, 지금까지의 관계분석·전략유형·예측결과를 함께 탐색할 수 있도록 Power BI 대시보드로 통합했습니다.

## 3. 슬라이드 3 — 69/69와 66/66의 차이

- 원자료 캠퍼스 행 검증: 69/69 PASS
- 최종 분석자료 대학-연도 검증: 66/66 PASS

설명:

> 69와 66은 검증 단위가 다릅니다. 원자료에서는 일부 대학이 캠퍼스별로 별도 행으로 공시되어 총 69개의 캠퍼스 행이 존재합니다. 먼저 각 캠퍼스 행의 정원내 모집인원·지원자·입학자를 이용해 충원율과 경쟁률을 재계산하여 공시값과 비교했습니다. 이후 동일 대학의 캠퍼스가 분리되어 있는 경우 비율을 단순평균하지 않고 모집인원·지원자·입학자 수를 먼저 합산한 뒤 대학 단위로 지표를 다시 계산했습니다. 그렇게 최종 분석단위인 22개 대학 × 3개년 = 66개 대학-연도 관측치가 구성되었습니다.

핵심 산식:

- 충원율 = 정원내 입학자 / 정원내 모집인원 × 100
- 경쟁률 = 정원내 지원자 / 정원내 모집인원

## 4. 슬라이드 8 — 전략 유형화 기준

기준값은 외부 공식 기준이 아니라 분석 대상 22개 대학의 실제 3개년 평균 분포에서 계산한 상대적 기준이다.

- 평균 충원율 중앙값: 99.8%
- 평균 경쟁률 중앙값: 7.5167
- 평균 취업률 75분위수: 67.5525%
- 충원율 표준편차 중앙값: 0.23094

왜 중앙값을 사용했는가:

> 평균보다 극단값의 영향을 덜 받고, 22개 대학을 상대적인 상·하 집단으로 나누기에 직관적이기 때문입니다.

왜 취업률만 75분위수인가:

> 취업성과 기반 잠재형은 단순 평균 이상이 아니라, 입학성과는 상대적으로 낮지만 취업성과가 뚜렷하게 높은 대학을 구분하려는 목적이었기 때문에 상위 25% 기준을 사용했습니다.

분류 순서:

1. 충원율↑ + 경쟁률↑ + 안정 → 충원 안정·수요 강세형
2. 충원율↑ + 안정 → 충원 안정형
3. 충원율↑ + 경쟁률↑ → 입시 수요 강세형
4. 취업률 상위 + 충원율↓ → 취업성과 기반 잠재형
5. 충원율↓ + 경쟁률↓ → 입학성과 보완 필요형
6. 그 외 → 관찰 필요형

대표 사례:

- 서울과기대: 충원 99.97, 경쟁 12.97, SD 0.058 → 충원 안정·수요 강세형
- 창신대: 충원 100.00, 경쟁 7.23, SD 0.000 → 충원 안정형
- 연세대: 충원 100.20, 경쟁 10.50, SD 1.127 → 입시 수요 강세형
- 성균관대: 충원 99.53, 취업 73.88 → 취업성과 기반 잠재형
- 부산외대: 충원 99.57, 경쟁 3.83 → 입학성과 보완 필요형
- 부산대: 충원 99.77, 경쟁 9.43 → 관찰 필요형

주의:

- 유형은 대학의 절대적 우열이 아니라 22개 대학 표본 내부의 상대적 진단이다.
- 표본·기간·기준값이 바뀌면 유형도 달라질 수 있다.
- 강서대는 충원율 SD가 기준값과 거의 동일한 경계 사례로, 부동소수점 차이에 따라 안정형 조건을 아주 미세하게 벗어난다.

## 5. 슬라이드 9 — 실제값 vs 예측값 그래프

그래프 해석:

- x축: 실제 신입생 충원율
- y축: Random Forest 예측 충원율
- 45도선에 가까울수록 예측이 정확함
- 45도선 위: 과대예측
- 45도선 아래: 과소예측

라벨이 붙은 4개 관측치는 임의 선정이 아니라 평가자료 17개 중 절대오차가 가장 큰 4개를 자동 표시한 것이다.

- 영산대 2023: 실제 90.60, 예측 95.50 → 절대오차 약 4.90%p
- 부산외대 2023: 실제 99.70, 예측 95.89 → 절대오차 약 3.81%p
- 대구대 2024: 실제 96.70, 예측 98.79 → 절대오차 약 2.09%p
- 협성대 2023: 실제 98.60, 예측 99.88 → 절대오차 약 1.28%p

왜 큰 오차가 발생할 수 있는가:

- 전체 66개, 학습자료 49개로 표본이 작음
- 충원율이 99~100% 부근에 집중되어 낮은 극단값을 학습하기 어려움
- 학과구조, 등록포기, 추가합격 이동 등 미관측 요인이 존재함
- Random Forest는 `n_estimators=300`, `max_depth=4`, `min_samples_leaf=2`로 과적합을 제한하고 있어 극단값을 그대로 따라가기보다 평균적인 패턴에 가까운 예측을 할 수 있음
- 대학-연도 단순 무작위 분할이므로 같은 대학의 다른 연도가 train/test에 동시에 존재할 수 있음

중요한 방어 문장:

> 이 네 대학이 항상 예측하기 어려운 대학이라는 의미는 아닙니다. 이번 random_state=42 단일 평가분할에서 해당 대학-연도 관측치가 상대적으로 큰 오차를 보였다는 뜻입니다.

> 개별 관측치의 오차를 특정 한 변수 때문이라고 단정할 수는 없습니다. 정확한 local explanation을 위해서는 SHAP value나 decision path 분석이 추가로 필요합니다.

## 6. 발표 시 표현 원칙

- 상관관계는 인과관계로 표현하지 않는다.
- p=.056은 “거의 유의”가 아니라 “5% 유의수준에 근접했으나 유의하지 않음”으로 표현한다.
- Random Forest 변수 중요도 .586은 “58.6%를 설명한다”는 의미가 아니다.
- 전략점수는 대학 종합순위가 아니다.
- 단일 split 성능과 5-fold CV 성능을 반드시 구분한다.
- 예측모형은 확정적 미래예측이 아니라 탐색적 예측구조로 해석한다.
