# 데이터 확보 가능성 검토표

본 문서는 교육 공공데이터 기반 대학 입학성과 분석 및 예측 프로젝트에서 활용 가능한 데이터를 사전에 검토하기 위한 자료이다.
데이터의 존재 여부뿐만 아니라 실제 분석 가능성, 다운로드 가능성, 분석 단위, 제공 기간, 주요 변수 등을 함께 확인한다.

## 1. 데이터 검토 기준

| 기준       | 확인 내용                                                               |
| -------- | ------------------------------------------------------------------- |
| 접근 가능성   | 공개자료인지, 회원가입 또는 별도 신청이 필요한지 확인                                      |
| 다운로드 가능성 | CSV, Excel, XLSX 등 분석 가능한 형식으로 받을 수 있는지 확인                          |
| 분석 단위    | 연도별, 지역별, 대학별, 학과별 등 프로젝트 분석 단위와 맞는지 확인                             |
| 제공 기간    | 시계열 분석 또는 추세 분석이 가능할 만큼 여러 연도 자료가 있는지 확인                            |
| 주요 변수    | 학령인구, 고등학교 졸업자 수, 대학 진학률, 입학정원, 충원율, 경쟁률, 취업률 등 필요한 변수가 포함되어 있는지 확인 |
| 활용 가능성   | 본 프로젝트의 연구문제와 직접 연결되는지 확인                                           |

## 대학알리미 데이터 활용 가능성 확인

- 확인 데이터: 신입생 충원율, 재학생 충원율
- 제공 기관: 대학알리미
- 조회 가능 기간: 2023년 ~ 2025년
- 학교 구분: 대학, 전문대학, 대학원, 대학원대학 등
- 분석 단위: 학교별 평균 또는 학과별 통계
- 다운로드 가능 여부: Excel 다운로드 가능
- 활용 가능성: 높음

### 활용 방향

신입생 충원율은 대학 입학성과를 나타내는 핵심 종속변수로 활용할 수 있다.  
재학생 충원율은 대학 운영 안정성 또는 학생 유지 수준을 보여주는 보조 지표로 활용할 수 있다.

초기 분석에서는 학교별 평균 자료를 중심으로 연도별·대학별 변화를 분석하고, 필요할 경우 학과별 통계로 확장한다.

### 주의할 점

학과별 통계는 학교마다 학과명과 분류 체계가 다를 수 있으므로 전처리 과정이 복잡할 수 있다. 따라서 1차 분석에서는 학교별 평균 자료를 우선 활용하는 것이 적절하다.

* 분석 단위가 연도별·지역별·대학별로 정리되어 있으면 본 프로젝트의 핵심 분석에 활용한다.
* 데이터가 10년 이상 확보되면 시계열 분석 또는 예측모델 구축 후보로 검토한다.
* 데이터가 3~5년 정도만 확보되면 추세 분석 또는 비교 분석 중심으로 활용한다.
* 학생 개인자료나 개별 합격 여부 자료처럼 접근이 어려운 데이터는 핵심 분석에서 제외한다.
* 다운로드가 어렵거나 PDF 형태로만 제공되는 자료는 보조자료로만 활용한다.

* 재학생 충원율: 대학 운영 안정성 및 학생 유지 수준을 보여주는 보조 지표
* 졸업생 취업 현황: 대학의 진로 성과 및 대학 선택 요인으로 활용 가능

### 최종 판단

대학알리미 자료는 연도별·학교유형별 조회가 가능하고 Excel 다운로드도 지원하므로 본 프로젝트에 활용 가능성이 높다. 초기 분석에서는 대학과 전문대학을 중심으로 학교별 평균 자료를 우선 활용하고, 필요할 경우 학과별 자료나 대학원 자료로 분석 범위를 확장한다.

## KOSIS 데이터 활용 가능성 확인 예정

### 확인 목적

대학 입학성과에 영향을 줄 수 있는 외부 환경 변수를 확보하기 위해 KOSIS 자료를 확인한다. 대학알리미가 대학별 충원율, 취업률, 재정 지표를 제공한다면, KOSIS는 학령인구, 지역별 인구, 고등학교 졸업자 수, 대학 진학률 등 대학 입학성과에 영향을 줄 수 있는 사회·인구학적 변수를 제공할 수 있다.

### 우선 확인할 데이터 항목

* 학령인구
* 시도별 연령별 인구
* 고등학교 졸업자 수
* 대학 진학률

### 프로젝트 활용 방향

* 학령인구: 대학 입학 수요 감소를 설명하는 핵심 변수
* 시도별 연령별 인구: 지역별 입학 가능 인구 규모를 나타내는 변수
* 고등학교 졸업자 수: 대학 진학 대상자 규모를 보여주는 변수
* 대학 진학률: 지역별 대학 진학 수요를 보여주는 변수

### 최종 확인할 점

* 연도별 자료 제공 여부
* 시도별 또는 지역별 구분 가능 여부
* Excel 또는 CSV 다운로드 가능 여부
* 대학알리미 자료와 연도·지역 기준으로 결합 가능한지 여부
  
## KOSIS 학령인구 데이터 활용 가능성 확인

### 확인 경로

* 제공 기관: KOSIS 국가통계포털
* 확인 데이터: 학령인구 관련 통계
* 조회 가능 기간: 과거 연도부터 장래 추계 연도까지 확인 가능
* 지역 구분: 전국 및 시도별 구분 가능
* 다운로드 가능 여부: Excel, CSV, TXT 등 다양한 형식으로 다운로드 가능

### 프로젝트 활용 방향

KOSIS의 학령인구 자료는 대학 입학성과에 영향을 줄 수 있는 외부 환경 변수로 활용할 수 있다. 특히 학령인구 감소는 대학 신입생 충원율 변화와 직접적으로 연결될 수 있으므로, 본 프로젝트에서 신입생 충원율을 설명하는 핵심 설명변수로 활용 가능하다.

### 변수 활용 가능성

* 학령인구: 대학 입학 수요 감소를 설명하는 핵심 변수
* 전국 단위 자료: 전체적인 학령인구 감소 추세 파악에 활용
* 시도별 자료: 지역별 대학 입학 수요 차이 분석에 활용
* 장래 추계 자료: 향후 대학 입학성과 변화 전망에 활용 가능

### 최종 판단

KOSIS 학령인구 자료는 연도별·지역별 조회가 가능하고 Excel, CSV, TXT 등 다양한 형식으로 다운로드할 수 있으므로 본 프로젝트에 활용 가능성이 높다. 대학알리미의 신입생 충원율 자료와 결합하면, 학령인구 변화가 대학 입학성과에 어떤 영향을 미치는지 분석할 수 있다.

## KOSIS 고등학교 졸업자 수 자료 탐색 결과

### 확인 내용

KOSIS에서 고등학교 졸업자 수 관련 자료를 탐색하였으나, 검색 결과에서 본 프로젝트 목적에 직접적으로 적합한 통계표를 찾는 데 어려움이 있었다. 일부 검색 결과는 특정 전공 분야 졸업자 수나 졸업 고등학교 유형 비율 자료로 나타났으며, 이는 본 프로젝트에서 필요한 전체 고등학교 졸업자 수 또는 대학 진학 대상자 규모를 직접적으로 보여주는 자료와는 차이가 있었다.

### 최종 판단

KOSIS에서는 우선 학령인구 및 시도별 인구 자료를 중심으로 활용하고, 고등학교 졸업자 수와 대학 진학률 자료는 교육통계서비스 또는 별도의 교육통계 자료에서 추가로 탐색하는 것이 적절하다.

### 프로젝트 활용 방향

* KOSIS: 학령인구, 시도별 인구, 연령별 인구 등 외부 환경 변수 확보
