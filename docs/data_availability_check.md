# 데이터 확보 가능성 검토표

본 문서는 교육 공공데이터 기반 대학 입학성과 분석 및 예측 프로젝트에서 활용 가능한 데이터를 사전에 검토하기 위한 자료이다.
데이터의 존재 여부뿐만 아니라 실제 분석 가능성, 다운로드 가능성, 분석 단위, 제공 기간, 주요 변수 등을 함께 확인한다.

## 1. 데이터 검토 기준

| 기준       | 확인 내용                                                               |
| -------- | ------------------------------------------------------------------- |
| 접근 가능성   | 공개자료인지, 회원가입 또는 별도 신청이 필요한지 확인                                      |
| 다운로드 가능성 | CSV, Excel, XLSX 등 분석 가능한 형식으로 받을 수 있는지 확인                          |
| 분석 단위    | 연도별, 지역별, 대학별, 학과별 등 프로젝트 분석 단위와 맞는지 확인                             |
| 제공 기간    | 시계열 분석 또는 추세 분석이 가능할 만큼 여러 연도 자료가 있는지 확인                            |
| 주요 변수    | 학령인구, 고등학교 졸업자 수, 대학 진학률, 입학정원, 충원율, 경쟁률, 취업률 등 필요한 변수가 포함되어 있는지 확인 |
| 활용 가능성   | 본 프로젝트의 연구문제와 직접 연결되는지 확인                                           |

## 2. 데이터 활용 가능성 등급

| 등급 | 의미                                 |
| -- | ---------------------------------- |
| A  | 바로 다운로드 가능하며 본 프로젝트의 핵심 분석에 활용 가능  |
| B  | 데이터는 확보 가능하지만 전처리 또는 추가 가공이 필요     |
| C  | 자료는 존재하나 접근성, 분석 단위, 변수 구성에 제한이 있음 |
| X  | 확보가 어렵거나 본 프로젝트 분석에 부적합            |

## 4. 우선 확인할 핵심 데이터

1. KOSIS 학령인구 및 지역별 인구 자료
2. 교육통계서비스 고등학교 졸업자 수 및 대학 진학률 자료
3. 대학알리미 대학별 신입생 충원율 자료
4. 대학알리미 대학별 취업률 및 중도탈락률 자료
5. 학교알리미 진로선택과목 관련 자료

## 5. 데이터 검토 후 판단 기준

데이터를 확인한 뒤 다음과 같이 판단한다.

* 분석 단위가 연도별·지역별·대학별로 정리되어 있으면 본 프로젝트의 핵심 분석에 활용한다.
* 데이터가 10년 이상 확보되면 시계열 분석 또는 예측모델 구축 후보로 검토한다.
* 데이터가 3~5년 정도만 확보되면 추세 분석 또는 비교 분석 중심으로 활용한다.
* 학생 개인자료나 개별 합격 여부 자료처럼 접근이 어려운 데이터는 핵심 분석에서 제외한다.
* 다운로드가 어렵거나 PDF 형태로만 제공되는 자료는 보조자료로만 활용한다.
