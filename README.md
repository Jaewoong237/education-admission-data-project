# Education Admission Data Project

## 프로젝트 개요

본 프로젝트는 교육 관련 공공데이터를 활용하여 학령인구 변화, 고등학교 졸업 및 진학 지표, 대학 신입생 충원율, 취업률, 경쟁률 등을 종합적으로 분석하고, 대학 입학성과와 입시 전략 인사이트를 도출하는 것을 목표로 한다.

분석 대상은 2023년부터 2025년까지의 22개 대학 자료이며, 대학알리미, KOSIS 국가통계포털, 교육통계서비스 등에서 수집한 데이터를 기반으로 분석을 수행하였다.

본 프로젝트는 데이터 수집, 전처리, 통합 데이터 구축, 탐색적 데이터 분석, 상관분석, 회귀분석, 예측모형 구축, 대학별 입학성과 유형화, Power BI 대시보드 제작, 최종보고서 작성까지의 과정을 포함한다.

## 연구 배경

청소년부 지도교사로 섬기며 학생들의 진로, 진학, 과목 선택에 대한 고민을 접하게 되었다. 그러나 고교학점제 도입, 입시제도 변화, 교과목 이수체계 변화, 학령인구 감소 등으로 인해 기존의 경험과 제한적인 정보만으로는 학생들에게 충분한 도움을 주기 어렵다는 한계를 느꼈다.

이에 따라 교육 공공데이터를 기반으로 입시환경과 교육시장 변화를 분석하고, 향후 학생 맞춤형 진학 설계 및 학습 설계 연구로 확장하기 위한 기초 프로젝트를 수행하고자 하였다.

## 분석 방법 및 도구

### Python 기반 분석

본 프로젝트의 핵심 데이터 수집, 전처리, 통합, 탐색적 분석, 상관분석, 회귀분석, 예측모형 구축, 대학 유형화 분석은 Python을 중심으로 수행하였다.

Python을 활용함으로써 분석 전 과정을 코드 기반으로 재현 가능하게 구성하고, GitHub 저장소를 통해 분석 흐름과 결과물을 관리하였다.

주요 활용 라이브러리는 다음과 같다.

* pandas
* numpy
* matplotlib
* statsmodels
* scikit-learn

### SPSS 기반 통계분석 검증

SPSS는 주요 통계분석 결과를 보조적으로 검토할 수 있는 도구로 설정하였다. 특히 신입생 충원율과 취업률, 진학률, 경쟁률 간의 기술통계, 상관분석, 회귀분석 결과를 SPSS에서 재확인함으로써 Python 분석 결과의 해석 타당성을 보완할 수 있다.

### Power BI 대시보드 제작

Power BI는 분석 결과를 대시보드 형태로 시각화하기 위한 도구로 활용하였다. 대학-연도별 패널 데이터, 대학별 평균 지표, 전략 유형, 예측모형 성능, 변수 중요도 데이터를 Power BI용 CSV 파일로 생성하였고, 이를 바탕으로 대시보드를 제작하였다.

대시보드는 신입생 충원율, 경쟁률, 취업률, 진학률, 대학별 전략 유형, 예측모형 결과를 종합적으로 탐색할 수 있도록 구성하였다.

## 연구문제 1. 학령인구 및 고교 진학 지표와 신입생 충원율 관계 분석

이를 통해 신입생 충원율을 단순한 대학 내부 지표로만 보는 것이 아니라, 학령인구 감소와 고등교육 진학 흐름 속에서 해석할 수 있는 분석 기반을 마련하였다.

분석 결과는 `reports/fill_rate_population_relation/`에 저장하였다.

## 연구문제 2. 취업성과와 신입생 충원율 관계 분석

2023~2025년 22개 대학, 총 66개 대학-연도 자료를 바탕으로 신입생 충원율과 취업률, 진학률, 경쟁률 간의 관계를 분석하였다.

취업성과 자료는 대학알리미 졸업생 취업현황 원자료를 재검토하여 졸업자, 취업자, 진학자, 입대자, 취업불가능자, 외국인유학생, 제외인정자 항목을 기준으로 취업률 계산분모를 재구성하였다. 수정된 전처리 결과는 66개 대학-연도 전체에 대해 원자료와 재계산 값을 대조하여 검증하였다.

Pearson 상관분석 결과, 신입생 충원율은 경쟁률과 r=0.425(p<.001), 진학률과 r=0.407(p<.001)의 유의한 양의 상관을 보였다. 반면 취업률과 충원율의 상관은 r=0.105(p=.400)로 낮았으며 통계적으로 유의하지 않았다.

연도를 통제한 다중회귀분석 결과, 모형 전체는 통계적으로 유의하였다(R²=0.259, Adjusted R²=0.197, F(5,60)=4.197, p=.002). 경쟁률은 B=0.454(p=.009), 진학률은 B=0.166(p=.027)로 충원율과 유의한 양의 관계를 보였으며, 취업률은 B=-0.117(p=.225)로 통계적으로 유의하지 않았다.

따라서 본 자료에서는 취업률 자체보다 경쟁률과 진학률이 대학 신입생 충원율과 상대적으로 더 밀접한 관련을 보이는 것으로 나타났다. 다만 본 분석은 관찰자료를 활용한 관계 분석이므로 인과관계로 해석하지 않는다.

분석 결과는 `reports/employment_fill_rate_relation/`에 저장하였다.

## 연구문제 3. 대학별 입학성과 유형화 및 입시 전략 인사이트

2023~2025년 22개 대학의 신입생 충원율, 경쟁률, 취업률, 진학률을 종합하여 대학별 입학성과 유형을 분류하였다. 대학별 3개년 평균 지표와 충원율 변동성을 산출하고, 충원율·경쟁률·취업률·안정성 지표를 바탕으로 전략 점수를 계산하였다.

분석 결과, 대학 유형은 다음과 같이 분류되었다.

| 유형 | 대학 수 |
| --- | ---: |
| 입학성과 보완 필요형 | 6 |
| 관찰 필요형 | 5 |
| 충원 안정·수요 강세형 | 5 |
| 충원 안정형 | 3 |
| 입시 수요 강세형 | 2 |
| 취업성과 기반 잠재형 | 1 |

특히 영산대학교는 수정된 취업률을 반영한 결과 취업성과 기준 상위 25% 경계값을 소폭 상회하면서 기존 '입학성과 보완 필요형'에서 '취업성과 기반 잠재형'으로 재분류되었다.

이를 통해 대학별 입학성과를 단순한 충원율 수치로만 보는 것이 아니라, 경쟁률, 취업성과, 안정성까지 종합적으로 고려하여 입시 전략 방향을 도출할 수 있었다.

특히 충원율과 경쟁률이 모두 낮은 대학은 모집단위별 수요 점검과 지역 맞춤형 홍보 전략이 필요하며, 취업성과가 양호하지만 입학성과가 약한 대학은 취업률과 졸업 후 진로 성과를 입시 홍보 메시지로 강화할 필요가 있다.

분석 결과는 `reports/admission_strategy_types/`에 저장하였다.

## 연구문제 4. 신입생 충원율 예측모형 분석

신입생 충원율을 설명하거나 예측하는 주요 요인을 탐색하기 위해 선형회귀, 릿지회귀, 랜덤포레스트 회귀모형을 적용하였다.

설명변수로는 경쟁률, 취업률, 진학률, 연도, 입학정원, 모집인원, 지원자 수, 지역, 설립구분, 수도권/지방, 분석그룹 등을 활용하였다.

단일 훈련/테스트 데이터 분할 기준에서는 선형회귀모형이 가장 우수한 성능을 보였으며, 테스트 데이터 기준 RMSE는 2.399, R²는 0.582로 나타났다.

반면 5-fold 교차검증에서는 랜덤포레스트가 평균 RMSE 2.995, 평균 R² 0.411로 가장 안정적인 일반화 성능을 보였다. 따라서 단일 테스트셋에서는 선형회귀가 우수했지만, 반복적인 교차검증 기준에서는 랜덤포레스트가 상대적으로 안정적인 것으로 해석하였다.

랜덤포레스트 변수 중요도에서는 진학률과 경쟁률이 가장 높은 비중을 차지하였으며, 취업률은 그보다 낮은 상대적 중요도를 보였다. 변수 중요도는 인과적 영향의 크기가 아니라 해당 모형 내 상대적 예측 기여도로 해석한다.

따라서 신입생 충원율은 경쟁률, 취업률, 진학률, 대학 규모 및 지역 특성을 함께 고려할 때 일정 수준 설명 가능하다는 점을 확인하였다.

다만 분석 대상이 22개 대학의 3개년 자료, 총 66개 관측치로 제한되어 있으므로, 본 예측모형은 실제 입학성과를 정밀하게 예측하는 최종 모형이라기보다 주요 변수의 설명 가능성과 예측 활용 가능성을 탐색하는 보조 분석으로 해석하는 것이 적절하다.

분석 결과는 `reports/fill_rate_prediction_model/`에 저장하였다.

## 연구문제 5. Power BI 대시보드용 데이터셋 및 최종 인사이트 구성

연구문제 1~4의 분석 결과를 종합하여 Power BI 대시보드에서 활용할 수 있는 통합 데이터셋을 생성하였다. 대학-연도 단위 패널 데이터, 대학별 평균 지표 및 전략 유형 요약, 연구문제별 분석 요약, KPI 요약, 예측모형 성능 및 변수 중요도 데이터를 구성하였다.

이를 바탕으로 Power BI 대시보드를 제작하여 신입생 충원율, 경쟁률, 취업률, 진학률, 대학별 전략 유형, 예측모형 결과를 하나의 대시보드에서 종합적으로 확인할 수 있도록 하였다.

Power BI 대시보드는 다음과 같은 구조로 구성하였다.

1. 프로젝트 개요

   * 분석 대학 수
   * 분석 연도 수
   * 전체 관측치 수
   * 평균 신입생 충원율

2. 입학성과 현황

   * 연도별 평균 신입생 충원율
   * 지역별 평균 신입생 충원율
   * 국립·사립별 평균 신입생 충원율

3. 취업성과 및 입시지표 관계

   * 취업률과 신입생 충원율 관계
   * 경쟁률과 신입생 충원율 관계
   * 진학률과 신입생 충원율 관계

4. 대학별 전략 유형

   * 전략 유형별 대학 수
   * 전략 점수 상위 10개 대학
   * 대학별 전략 유형 요약 표

5. 예측모형 결과

   * 테스트셋 RMSE 비교
   * 테스트셋 R² 비교
   * 5-fold 교차검증 성능 비교
   * 신입생 충원율 예측 변수 중요도

분석 결과 및 Power BI 대시보드용 데이터셋은 `reports/powerbi_dashboard_dataset/`에 저장하였다.

## 프로젝트 의의

본 프로젝트는 교육 공공데이터를 활용하여 대학 입학성과를 다각도로 분석했다는 점에서 의의가 있다.

단순히 신입생 충원율만 확인하는 것이 아니라, 학령인구 변화, 고교 졸업 및 진학 흐름, 취업성과, 경쟁률, 대학 특성, 예측모형, 전략 유형화까지 종합적으로 연결하였다.

또한 Python 기반 분석을 통해 데이터 처리와 분석 과정을 재현 가능하게 구성하였으며, Power BI 대시보드를 제작하여 분석 결과를 시각적으로 탐색할 수 있도록 하였다.

## 한계점 및 향후 보완 방향

본 프로젝트는 22개 대학의 2023~2025년 자료를 중심으로 수행되었기 때문에 분석 대상과 기간이 제한적이다. 따라서 분석 결과를 전체 대학으로 일반화하기에는 한계가 있으며, 향후 더 많은 대학과 장기 시계열 자료를 포함할 필요가 있다.

또한 본 분석은 대학 단위 자료를 중심으로 수행되었으므로, 모집단위별·전공계열별 세부 분석까지 확장할 필요가 있다. 향후 연구에서는 학과별 충원율, 전공계열별 취업성과, 지역 산업구조, 고교 유형, 학생 선호도 자료 등을 추가하여 보다 정교한 입시 전략 분석으로 발전시킬 수 있다.

추가적으로 SPSS를 활용한 통계분석 결과 검증을 수행하면 Python 기반 분석 결과의 해석 타당성을 보완할 수 있다. 또한 향후 Power BI 대시보드에 필터, 슬라이서, 상호작용 기능을 추가하면 분석 결과의 활용 가능성을 더욱 높일 수 있다.
